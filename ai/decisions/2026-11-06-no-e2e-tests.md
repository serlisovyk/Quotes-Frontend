# No end-to-end tests

Date: 2026-11-06 · Status: accepted

## Context

An end-to-end suite (Playwright, Cypress) driving the main scenario in a real browser was proposed. The
author rejected it.

## Decision

- No end-to-end framework and no browser-driven test suite in this repo; Jest + Testing Library only
  (`2026-11-06-tests-jest-tdd.md`).
- The author's choice, not a technical limit: unit and component tests written test-first cover the
  behavior, and a change is still used by hand in the browser before it is handed over
  (`ai/workflow.md`).
- Rejected: Playwright, Cypress and similar.

## Consequences

- Nobody adds an end-to-end tool without the author's explicit ask and a new record.
- The gap an end-to-end suite would fill is closed by more component and Server Action tests, not by a
  second runner.
