# Spec: 404 head and search tails (MY-379)

Plan: `ai/superpowers/plans/2026-11-07-my-379-404-search-fixes.md`.

## 404 robots

- The HTML of every 404 (`/nope`, `/quotes/abc`, `/quotes/999999999`) has exactly one
  `<meta name="robots">`, with `noindex`.
- Pages without their own rule carry no `robots` meta at all (an indexable page is the default); the
  edit and create pages keep their `noindex`.

## 404 header

- The status of every 404 stays 404 (`ai/decisions/2026-11-06-no-loading-above-not-found.md`).
- A 404 raised by `notFound()` inside a page is rendered by the browser: the server HTML is an empty
  shell, and the header, the footer and the message appear once the scripts run. An unknown URL
  (`/nope`) is rendered on the server with the header. This is Next.js behaviour, recorded as a decision.

## Search limit outside the list

- `/search?limit=15`: the limit select lists 10, 15, 20, 50 and shows 15; the search and the pagination
  already use 15.
- Only a valid limit (an integer from 1 to 50) that is not in the list is added, in numeric order. The
  list stays 10, 20, 50 for every other limit.

## Category highlight

- `/search?category=Life` highlights the tag `life` on the cards: it is marked current and, when the
  quote has more tags than fit, moves into the visible ones, exactly as for `life`.
