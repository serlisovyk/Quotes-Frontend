# Spec: search UX and category suggestions (MY-243)

## Behavior

- **Search form.** Fields: Text, Author, Category, Limit. No Offset field. Limit is a `<select>` with a
  visible label, options 10 / 20 / 50, shown as 10 until another is chosen; the chosen value goes to the URL
  as `limit`. A new search never carries an `offset`, so it starts on page 1.
- **Offset in the URL.** `limit` and `offset` stay in the URL. An offset that is not a multiple of the limit
  is aligned down (`offset=5&limit=10` is page 1, `offset=25&limit=10` is page 3, a negative or non-numeric
  offset is page 1). The page requests the aligned offset and the pagination counts pages by the limit, so
  Prev / Next never skip or repeat quotes.
- **Category in the search.** Uppercase letters are accepted (`Leadership`), the value is sent as typed. The
  error text for other characters: "Category can only contain letters, numbers and dashes." The quote form
  rules are unchanged (lowercase only).
- **Suggestions.** The Category field of the search form and the Categories field of the create / edit form
  suggest existing categories while the user types: at most 8 names, requested 250 ms after the last
  keystroke; an older request is cancelled when a newer one starts. Nothing is shown while there is no
  query, no match or an error (no toast).
- **Quote form token.** The categories field is comma-separated: suggestions are for the text after the last
  comma; choosing one replaces only that text (`life, cou` + courage becomes `life, courage`), the earlier
  categories stay untouched.
- **Combobox (ARIA).** The input has `role="combobox"`, `aria-autocomplete="list"`, `aria-controls` and
  `aria-expanded`; the list is `role="listbox"` with `role="option"` items; the highlighted one is
  `aria-activedescendant`. ArrowDown / ArrowUp move (wrapping), Enter picks the highlighted option (and does
  not submit the form), Escape closes the list, a click picks an option, leaving the field closes the list.
  With no highlighted option Enter submits the form as before.

## Out of scope

Suggestions for the author field, a live-region announcement of the result count, caching suggestions,
highlighting a selected category typed in uppercase on the quote cards.
