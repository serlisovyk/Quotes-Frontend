# Spec: read-only mode (MY-382)

Plan: `ai/superpowers/plans/2026-11-07-my-382-read-only.md`.

## The flag

- `READ_ONLY=true` (case-insensitive, surrounding spaces ignored) turns read-only mode on. Any other
  value, an empty one or no variable leaves the site exactly as it is without the flag.

## Read-only mode

- The menu (desktop bar and mobile dialog) has Home, Random and Search; there is no «Create New».
- The quote page shows the quote only: no Edit button and no Delete button.
- `/quotes/create` and `/quotes/:id/edit` answer 404 (the 404 page), whatever the id.
- `createQuoteAction`, `updateQuoteAction` and `deleteQuoteAction` do not call the API, do not revalidate
  and do not redirect. The two form actions return the form state with the submitted values and the
  form error «The site is read-only: quotes cannot be created, changed or deleted.»; the delete action
  returns `{ error }` with the same text.
- The home page header has no «Create New» either (checked on a production build).

## Without the flag

- Menu, quote page, create and edit pages and the three actions behave as before.
