# Plan: 404 head and search tails (MY-379)

Branch `my-379-404-search-fixes`. Behavior: `ai/superpowers/specs/2026-11-07-my-379-404-search-fixes.md`.

## Author's decisions (2026-11-07)

- A limit outside 10/20/50 is shown in the select as an extra option; the list itself does not change.

## Root causes (reproduced on a production build and in `next dev`)

- **Two `robots`.** The root layout sets `robots: { index: true, follow: true }`; for a 404 Next.js adds
  its own `<meta name="robots" content="noindex">` before the metadata, so both are rendered.
- **No header in `/quotes/abc`.** `notFound()` in a page escapes the server render before the shell
  flushes. Next.js 16.4 then answers 404 with `<html id="__next_error__">` and an empty body, and the
  browser renders the layout and `not-found.jsx` from the inlined data. A bare `notFound()` page and a
  layout reduced to `{children}` behave the same, so no component of ours is the cause. `/nope` has
  no page to throw from and is rendered normally. A `Suspense` around `{children}` brings the header
  into the server HTML, but the status turns 200 (`no-loading-above-not-found`).
- **Limit.** The select options are fixed to 10/20/50, the value is the URL one.
- **Category.** `getDisplayedCategories` and `CategoryTag` compare with `===`.

## Decisions in this plan

- **Robots:** drop `robots` from the layout metadata (an indexable page needs no tag); nothing else
  changes. The edit and create pages keep their own `noindex`.
- **Header:** no code change: the status 404 is worth more than the server-rendered header, and a layout
  `Suspense` is already rejected. Record it as a decision so nobody "fixes" it with a `Suspense`. The
  only proof possible without an end-to-end test is the curl check below.
- **Limit:** `createSearchInputFields` adds the URL limit to the options when it is a valid integer 1..50
  outside the list, sorted numerically; the value is normalised (`015` becomes `15`).
- **Category:** compare case-insensitively with a small `isSameCategory` util used by
  `getDisplayedCategories` and `CategoryTag`.
