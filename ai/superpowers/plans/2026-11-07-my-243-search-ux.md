## Author's decisions (2026-11-07)

Binding, from the issue: limit select 10 / 20 / 50, no offset field, URL keeps `limit` + `offset` with the
offset aligned down; a custom ARIA combobox shared by the search and quote forms, token after the last comma
in the quote form; uppercase accepted in the category search; a Route Handler `GET` over
`fetchCategoriesResult` with debounce and cancellation; TDD, thresholds do not drop.

## Decisions made in this plan

- **Route Handler, not a Server Action.** Actions are queued one at a time and cannot be aborted, so a stale
  suggestion request would block the next one; a `GET` can be cancelled with `AbortController`. Recorded in
  `ai/decisions/2026-11-07-category-suggestions-route-handler.md`.
- **Where the client fetch lives.** ESLint allows the global `fetch` only in `src/services`, so the browser
  call is `services/category-suggestions` (no `server-only`, it talks to our own `/api/categories`, never to
  `API_URL`). The architecture rule and the map say so.
- **Route.** `src/app/api/categories/route.js`: reads `name`, answers 400 `{ categories: [] }` for a missing
  or invalid name, otherwise `fetchCategoriesResult({ name, limit })` with the fixed limit
  `CATEGORY_SUGGESTIONS_LIMIT` (the client cannot widen it); a failed read is 502. The fetcher is not changed.
- **Numbers.** Debounce 250 ms, 8 suggestions (constants in `search.constant.js`).
- **Alignment** lives in `utils/pagination`: `alignOffset(offset, limit)` and
  `alignQueryParams(queryParams)` (the page fetches with it); `Pagination` uses `alignOffset` too.
- **Offset leaves the form, not the URL.** `ALLOWED_SEARCH_PARAM_NAMES` keeps `offset`;
  `SEARCH_FORM_FIELD_NAMES` is what the form submits. `INITIAL_SEARCH_VALUES` and validation lose `offset`.
- **Fields.** `FormField` picks the control by the config's `control` (`input`, `select`, `category`) for both
  forms; new components `SelectField`, `CategoryField`, `CategorySuggestions`; `InputField` gets `inputProps`
  and `children` so the combobox reuses its label, clear button and error. Control classes shared by input and
  select move to `field.constant.js`.
- **Hooks.** `useCategorySuggestions(query)`: debounce, abort, stale results ignored, `[]` on error.
  `useCategoryField(props)`: open state, active option, keyboard, selection. Pure helpers in `utils`:
  `category-token` (token after the last comma, replacing it, valid suggestion query), `get-next-option-index`,
  `isCategorySearchName` in `validation`.
- **Case.** `CATEGORY_SEARCH_REGEX = /^[a-z0-9-]+$/i` for the search field and the route; the quote form keeps
  `CATEGORY_NAME_REGEX`.
